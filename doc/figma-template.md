# Figma 模板与旧稿接入

每个链接指向一个 Frame、Component 或 Instance 画板。画板内部需有且只有一个可见的对应图层：

```text
启动图手机画板
├── splash/background
├── splash/foreground
└── splash/branding
```

- `background`：变换后绝对边界覆盖整个画板的容器，只放背景。建议容器开启裁剪；Android 旧版会拉伸背景，因此不要将文字、Logo 放在此层。
- `foreground`：主文案及关联装饰作为一个导出整体。容器变换后的边界应包含全部视觉内容，避免阴影、花饰越界被裁掉。
- `branding`：Logo、名称和标语组成一个整体，放在画板底部区域。手机和 Pad 使用同样比例的内容，整体等比缩放。
- 画板内的状态栏、时间、Home 指示条等参考元素应隐藏，不属于上述三个角色。
- 旋转和镜像图层直接使用 Figma 导出的 PNG，布局采用变换后的绝对边界，不按原始局部尺寸布局，也不二次旋转或翻转。导出比例不符时仍拒绝同步；必要时可用完整 Frame 包裹视觉内容。
- 工具使用图层绝对边界和 PNG 导出，不依赖本地字体。导出倍率 3x，Android 系统图标另行生成安全画布。
- 工具不会编辑、重命名或写回 Figma，也不自动选择最像 Logo 的图层。

画板推荐按逻辑尺寸绘制，例如手机 375×812、Pad 834×1194。若直接使用 3 倍像素画板，工具会误认为它是逻辑大窗口；请先规范 Figma 画板尺寸。

旧设计稿保留原名称，配置角色对应的节点 ID：

```yaml
splash:
  figma:
    phone:
      url: https://www.figma.com/design/文件ID?node-id=1-2
      nodes:
        background: "10:1"
        foreground: "10:2"
        branding: "10:3"
```

映射必须指向该画板内可见的后代节点。工具会拒绝缺失、重复、隐藏或越出指定画板关系的映射。背景容器尺寸必须与画板一致；背景内部可有渐变、模糊图层等。

手机和 Pad 可来自不同文件；同一个文件的多个画板会固定同一个 Figma 版本，素材导出也使用该版本。Figma 账号权限、API 限流或导出错误会终止同步，保留上次快照。

布局由图层参考尺寸与坐标推导：主视觉和品牌宽度参考两张稿插值，限制最大宽度与可用高度；保持安全边距和图层间距。三个平台的原生布局能力不同，构图预览仅用于初步检查，最终应验证目标设备的原生启动效果。
